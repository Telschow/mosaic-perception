Mosaic is a reproducible synthetic workbench for investigating when combining
noisy, asynchronous sensor observations improves object state estimates, and
when fusion can make results worse.

This site is built from the Markdown in the repository's `docs/` directory.
It makes no claim beyond [Implementation status](/mosaic-perception/implementation-status/) and
[Limitations](/mosaic-perception/limitations/). Benchmark numbers live only in the committed
[benchmark report](https://github.com/Telschow/mosaic-perception/blob/main/artifacts/benchmark/report.md).

More sensors don't automatically mean better tracking, in the synthetic scenarios
and settings tested. The clip is generated from the benchmark artifact; see
[Demos](/mosaic-perception/demos/) for how it is made.

## Interactive app (optional)

A Streamlit app is available when you run the repository locally. It is not
embedded or hosted here, and nothing on this site depends on it. See the
[app source](https://github.com/Telschow/mosaic-perception/blob/main/app/streamlit_app.py)
and run `uv run streamlit run app/streamlit_app.py`.
